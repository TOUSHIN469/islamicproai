# IslamicProAI 🚀
Bangladesh's First Halal Super App — AI Chat + E-commerce in One Platform

**Live:** https://example.ai (launching soon)

## Why I Built This
Bangladeshi Muslims use 3 different apps for Islamic AI, halal shopping, and rewards. I built one.

No VC. No team. Just code.

## What It Does
- **Halal AI Chat** — 4 models with smart fallback (Gemini, Mistral, DeepSeek, Qwen)
- **E-commerce** — Full shop with cart, orders, payments
- **Security** — Device fingerprint, rate limiting, encrypted sessions
- **Rewards** — Earn points for queries, redeem in shop

## Tech Stack
**Backend:** Python, Flask, Gunicorn  
**Database:** PostgreSQL, Redis  
**Security:** Werkzeug, itsdangerous, custom middleware  
**Infra:** Ubuntu, Nginx, Systemd
